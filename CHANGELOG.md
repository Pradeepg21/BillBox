# Changelog

Every code change bumps the version in `app/build.gradle.kts` (see "Versioning" in `CLAUDE.md`). Newest first.

## 1.1.0 (versionCode 2)

- Welcome tour on first launch, then the notification permission prompt.
- "How to use BillBox" guide with step-by-step help for every feature.
- Help (?) button on every screen opens the guide at the topic for that screen; also under More.
- "New to BillBox?" card on Home until the first bill is saved.

## 1.0.0 (versionCode 1)

- First release: bill capture with scan, gallery, PDF and share; on-device OCR; warranties with claim card and service history; recurring bills with reminders; insights and budgets; PDF and CSV export; app lock.
- Tablet layout with a navigation rail.
